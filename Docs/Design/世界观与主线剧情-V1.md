# 《星渊回响》世界观与主线剧情 V1

2026-11-06 · 剧情设计草案

用户希望主角以失忆开场，主线篇幅简短，其余设定由 Codex 自由拟写。下文归档了用户选作第一版的讨论稿。

## 开场

主角在一座废弃的观星塔外醒来。她忘了自己是谁，手里却攥着一把刻有自己名字的钥匙。每到入夜，塔里就会响起同一句话，用的是她自己的声音。

> “听到第三声钟响，就把门关上。别等我。”

## 世界观

山谷里有一道被称为**星渊**的裂谷。裂谷偶尔会把过去发生过的声音和动作重放出来，当地人称这些残留为**回响**。弱的回响可能只是一句话或一阵脚步声。强的回响能凝成实体，把过去发生过的事再做一遍。

故事发生在裂谷边的一座小村。村里的观星塔原本靠钟声给夜间过桥的人报信。昨晚，塔钟突然停在第二声。天亮后，村民发现旧桥上出现了一只徘徊的怪物，塔里也开始传出主角的声音。

## 主线流程

| 段落 | 玩家行动 | 剧情进展 |
| --- | --- | --- |
| 一、断钟 | 在村口与守桥人交谈，击败旧桥上的普通怪，回来报信。 | 怪物消散时发出了主角的声音。守桥人听完转述，认出她是昨夜进塔修钟的人。他还记得，那句“别等我”之后，第三声钟始终没响。 |
| 二、昨夜的路 | 沿旧桥前往观星塔，在塔外击败精英怪，调查残留的回响。 | 主角看见昨夜的片段。星渊异动时，她留下来拉住即将坠落的钟锤，让守桥人先带最后一批村民过桥。钟锤最终砸在塔内，冲击让她失去记忆，也留下了足以重演事故的回响。 |
| 三、第三声钟 | 进入塔顶，击败由钟塔守卫凝成的首领，夺回通往钟室的路。 | 入夜后，整座塔开始重演昨晚的事故。首领的攻击一次次震动钟架，钟锤一旦再次坠落，就会砸断旧桥。这一次，守桥人留在塔外拉住维修用的绞索。主角在塔内击败守卫，把钟锤引回原位，亲手敲响第三声。 |
| 尾声 | 回到村口，与守桥人做最后一次交谈。 | 钥匙上的名字依然让主角觉得陌生。守桥人问她接下来去哪。她把钥匙收起来，说：“你先带我走一遍吧。昨晚我们一起走的那条路。” |

主角在结尾仍然失忆。玩家可以拼出她昨晚做了什么，她则从别人的讲述和自己的行动里重新认识自己。昨晚她让守桥人先走，今天守桥人主动留下来帮她。

## 制作设想

- 按村口、旧桥、观星塔三个相连的区域规划。第一段可以沿用现有测试任务的接取、战斗、返回交付结构，工程进展见[当前开发状态](../Development/STATUS.md)。
- 三选一临时 Buff：完成特定任务或到达剧情指定地点时获得选择次数，例如塔顶首领战前。玩家借用一种昨夜残留的战斗回响，效果限时，到时自动结束（2026-11-23 用户调整，原为"持续到该战斗结束"）。
- 主线暂按约 20 分钟规划，实际时长待关卡搭建后试玩评估。
