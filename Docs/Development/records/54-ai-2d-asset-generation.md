# 54 · 2D 素材批量生成、预览与选稿

记录日期为 2026-11-26。工程对照基于 `b7b2f57` 和当时的本地界面配置。Claude Code 整理生图清单，Codex 负责本次对话中的图像生成、预览、重出和选稿登记。工程导入和配置另见[记录 53](53-ai-generated-assets-and-item-config.md)。本记录无独立 Issue。

## 用户观察与目标

用户希望分批为《星渊回响》制作图标、插画、特效贴图与区域概念图。候选放在工程外，先用 B1-1 确认纹章风格，切换到插画时先看 B4-1。B5 先等守桥人的外貌明确，再生成三视图和半身像。

## 用户提出的要求与调整

- **Buff 与道具图标**　用户跳过 B1-2，保留 B1-3 作为备用候选。B2 逐条附上观星币和星屑药剂，预览也和两张参考图并排。用户转发 Claude Code 的建议和提示词，将 B2-2 改为 B2-2b，画有厚卷边、铜锈和青光裂纹的钟沿碎片。
- **主视觉与区域布局**　用户确认 B4-1 的插画风格，指定 B4-2 参考 B4-1 v1 的构图。之后只要求重出 B7-1b 村口与 B7-4b 地图，每张附 B4-1 v1，并以固定布局开头（这段由 Claude Code 拟写，用户转发，见[记录 53](53-ai-generated-assets-and-item-config.md)）。从村子过一座直桥，沿对岸短台阶到圆形庭院，观星塔位于庭院后方。地图的虚线沿这条路线绘制。
- **守桥人**　用户确定为年龄不明的男性老者，先出两版三视图。选稿后，用户将 B5-2 从多表情改为单人半身像，每版画到腰带，表情平静温和，身体略朝左，背景透明。

Codex 用 `image_gen` 生成候选。每张登记文件名、日期、提示词编号、实际使用的提示词和工具，用到的参考图写入对应条目。道具和角色图以原尺寸 PNG 保存，缩放对照在预览中完成。

|---|---:|---|

| B2 道具图标 | 14 | 含 B2-2b 两版。按 96 × 96、`#544D8F` 和 140 × 140、`#6B5CAD` 两组显示条件，与观星币、星屑药剂并排对照 |
