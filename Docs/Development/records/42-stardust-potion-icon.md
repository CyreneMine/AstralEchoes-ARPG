# 42 · 星屑药剂图标设计与定稿

日期：2026-11-21。基于 `434a9af`，并只读核对本地背包预制件和观星币源图。

协助工具：Codex。相关 Issue：[#25 简单背包与道具表](https://github.com/CyreneMine/AstralEchoes-ARPG/issues/25)。

## 用户观察与目标

用户需要第三个道具的背包测试图标。用户将该道具命名为「星屑药剂」，计划使用 ID `2`，类型为消耗品，后续用于回血。用户给出的描述草稿为「用裂谷边采来的星屑熬成的药剂」。

## 用户提出的要求

药瓶以青蓝或蓝紫为主，带少量星点或四芒星。沿用[观星币](41-gold-coin-icon.md)的光照、描边和渲染风格，同时要在紫色背包格子里清楚可辨。用户要求先比较候选，选定后保存为 `Assets/Resources/Icon/Item/2.png`，按单张 Sprite 导入并开启透明度。本轮范围为图标和文档，玩法数据与界面接入留待后续。

## Codex 的分析与建议

本地 `BagSlot.prefab` 中图标的尺寸为 96 × 96，底色为 `(0.33, 0.30, 0.56)`。`BagPanel.prefab` 的详情区图标尺寸为 140 × 140，底色为 `(0.42, 0.36, 0.68)`。Codex 参照[观星币设计](41-gold-coin-icon.md)的左上高光、深色轮廓和四芒星，手工绘制两版透明 PNG，并在两种尺寸和底色下并排预览。

| 候选 | 设计与取舍 |
|---|---|
| A · 青蓝圆肚瓶 | 用圆肚、窄颈、瓶塞和青蓝液面明确药瓶轮廓。青蓝液体在紫底上容易区分。Codex 推荐作为普通消耗品图标 |
| B · 蓝紫切面瓶 | 用棱角和偏钴蓝的切面呼应裂谷星屑。与设定联系更直接，小尺寸下更像晶石容器 |

## 实际采纳与用户调整

用户选定 A 版并要求更新、推送文档。Codex 将选定的原图复制为 `Assets/Resources/Icon/Item/2.png`。PNG 和 `.meta` 随本地资源管理，恢复路径见[资源补回清单](../../ASSET_RESTORE.md)。

## 验证与当前状态

- **用户确认**：选择 A 版青蓝圆肚瓶。
- **静态与预览核验**：PNG 为 1024 × 1024，图像角点透明，文件 SHA-256 与所选候选一致。按背包格子和详情区尺寸、紫色底色查看过图标辨识度。
- **Unity 导入配置**：编辑器日志确认 PNG 已导入。保留 Unity 为 `2.png` 生成的 GUID，并在 `2.png.meta` 中采用 `1.png` 的导入设置，包括 Sprite（Single）和 Alpha Is Transparency。最终设置以 `.meta` 文件核对。
- **待接入与验证**：`ItemDatabase.asset` 当前只有 ID `0` 和 `1`，星屑药剂的道具记录、图标绑定及背包显示由 #25 跟踪。背包预览在 Unity 外完成，本轮没有 Play Mode 证据。
