# 2026-10-16 对话系统开发与收工日志

本日志按讨论阶段整理，不补造具体操作时刻。开发讨论跨前一晚至当前收工；日期采用 Asia/Shanghai。

| 阶段 | 用户观察/想法 | 辅助分析与实际结果 |
|---|---|---|
| 初始设计 | 触发点先显示 UI，再调用 DialogueMgr 载入数据 | 保留该顺序，补齐列表赋值、字典登记、更新钩子 |
| 初始化 | 用户提出 ShowMe 中处理管理器调用 | 最终在 ShowMe 同步登记面板，数据加载继续由触发点调用 |
| 文本推进 | 末句立即关闭、索引与判空疑问 | 修正索引捕获、空引用、末尾退出与互相递归；保留用户选择的 CheckNext 结构 |
| 动态选项 | 用户强调有几个选项就显示几个按钮 | 最终按数据分配数组并生成对应数量按钮，绑定文字与索引 |
| 输入衔接 | 选择与正文都处理鼠标释放 | 使用 lastChoiceFrame 屏蔽选择当帧正文输入 |
| 测试数据 | 用户指定 StreamingAssets 测试目录与 Test1_1.json | 生成5句、其中一组2选项的 UTF-8 JSON |
| UI 位置 | Scene 可见、Game 不见且位置不对 | 定位整个面板 SetParent 默认保留世界变换，用户改为 false |
| 收工确认 | 用户表示测试完成、本轮功能全部实现，留小漏洞明天修复 | 记录为用户整体测试确认；不追加独立运行验收或未提供的小漏洞细节 |

自编实现由用户完成；Codex 进行检查、解释、测试数据生成和归档。完整过程见 [实现记录](../records/14-dialogue-system-implementation.md)。本轮提交按 UI 基础、对话逻辑、测试数据、测试入口/场景、文档五批组织，实际哈希在交付清单记录。素材与第三方实现仍留本地，仅放行指定测试 JSON 及元数据。
